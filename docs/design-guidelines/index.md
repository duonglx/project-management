# Design Guidelines

## Overview

Design system and UI guidelines for the Project Management Platform using Tailwind CSS 4.

**Principles:** Clarity, Consistency, Accessibility, Responsiveness, Performance

## Documentation Structure

- **[Color System](./color-system.md)** - Color palette, semantic colors, dark mode
- **[Typography](./typography.md)** - Fonts, sizes, weights, line heights
- **[Components](./components.md)** - Buttons, cards, forms, badges, modals, navigation
- **[Responsive Design](./responsive-design.md)** - Breakpoints, patterns, mobile-first approach
- **[Accessibility](./accessibility.md)** - WCAG 2.1 AA compliance, keyboard navigation, ARIA

## Quick Reference

### Color Palette
- **Primary:** Blue (blue-600)
- **Success:** Green (green-500)
- **Warning:** Yellow (yellow-500)
- **Danger:** Red (red-500)
- **Neutral:** Gray scale

### Typography
- **Font:** System font stack (ui-sans-serif, system-ui...)
- **Sizes:** text-xs to text-4xl
- **Weights:** font-normal, font-medium, font-semibold, font-bold

### Breakpoints
- **sm:** 640px
- **md:** 768px
- **lg:** 1024px
- **xl:** 1280px
- **2xl:** 1536px

## Design Principles

1. **Clarity:** Information hierarchy clear and scannable
2. **Consistency:** Patterns repeat across application
3. **Accessibility:** WCAG 2.1 AA compliance target
4. **Responsiveness:** Mobile-first, adaptive layouts
5. **Performance:** Fast interactions, minimal layout shifts
