# Code Standards & Conventions

## Overview

This directory contains code standards and conventions for the Project Management Platform built with React 19, Vite 7, Redux Toolkit, and Tailwind CSS 4.

**Core Principles:** YAGNI, KISS, DRY

## Documentation Structure

- **[Tech Stack](./tech-stack.md)** - Dependencies, tools, and technology overview
- **[React Patterns](./react-patterns.md)** - Component structure, hooks usage, performance optimization
- **[Redux Conventions](./redux-conventions.md)** - State management patterns and best practices
- **[Styling Guide](./styling-guide.md)** - Tailwind CSS conventions and patterns
- **[Code Quality](./code-quality.md)** - ESLint, testing, git standards, security

## Quick Reference

### Tech Stack
- **Framework:** React 19.1.1
- **Build Tool:** Vite 7.1.2
- **State Management:** Redux Toolkit 2.8.2
- **Styling:** Tailwind CSS 4.1.12
- **Routing:** React Router DOM 7.8.1

### File Naming
- **Components:** PascalCase (`ProjectCard.jsx`)
- **Utilities/Services:** kebab-case (`api-client.js`)
- **Redux Slices:** camelCase (`workspaceSlice.js`)

### Key Conventions
- Functional components with hooks
- Redux Toolkit for state management
- Tailwind utility-first styling
- Mobile-first responsive design
- ESLint 9 flat config
- Conventional Commits
